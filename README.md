## 🚀 Projects

### 📈  [PINN Black-Scholes](https://github.com/TheoBradb/pinn-black-scholes)

A  **Physics-Informed Neural Network for solving the Black-Scholes PDE**.

I built this to explore whether a neural network could learn the solution to a financial PDE from the equation and boundary conditions alone, rather than from market data.

-   Implemented a mesh-free PINN in  **PyTorch**
    
-   Solves across continuous values of  **strike, volatility, interest rate and time**
    
-   Uses automatic differentiation to calculate derivatives of the learned solution
    
-   Added adaptive loss weighting and input normalisation to improve training
    
-   Compared predictions against the analytical Black-Scholes solution
    
-   Achieved pricing errors around  **0.01 absolute error**  on my test cases
    
-   Built an interactive  **3D volatility surface**  explorer with Streamlit
    

`Python`  `PyTorch`  `NumPy`  `SciPy`  `Plotly`  `Streamlit`
